## Ce que je fais

- **Développement web** : React, Next.js, Node.js, TypeScript
- **Développement mobile** : Flutter, React Native, paiements Mobile Money
- **SEO & GEO** : visibilité sur Google et dans les réponses des moteurs d'IA (ChatGPT, Gemini, Perplexity, Claude) — audit, contenu, Schema.org, suivi → [aroldjoutsop.tech/seo-geo](https://aroldjoutsop.tech/seo-geo/)

## Stack du site

Next.js (export statique), TypeScript, Tailwind CSS, i18n FR/EN, déployé sur Vercel.

Optimisations SEO/GEO intégrées : graphe JSON-LD (Person, WebSite, ProfessionalService, FAQPage), `llms.txt`, `robots.txt` ouvert aux robots des moteurs d'IA, sitemap, page de service rendue en HTML statique.

```bash
npm i
npm run dev
```
